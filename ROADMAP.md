# Roadmap

Roadmap items and TODOs are tracked in
[GitHub Project #6](https://github.com/users/SuryadevChippada/projects/6).

Each phase is an epic issue (`type: epic`) with its own milestone, in the
priority order NODUS is built in. See
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for verified current status.

## Adding a roadmap item

Open an issue using the Feature request, Bug report, or Provider request
template (see [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE)), label it
with the relevant `type:` and `area:`, and add it to the Project. Larger,
multi-step themes get a `type: epic` issue with child issues linked to it,
following the pattern of the existing phase epics.

## Out of scope for now

- Cloud accounts or a hosted NODUS service
- Telemetry or analytics of any kind
- Mobile platforms
