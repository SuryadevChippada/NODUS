# Support

NODUS is pre-alpha and maintained part-time. Please choose the right
channel so things get seen:

## GitHub Discussions — questions, ideas, help

Use [Discussions](https://github.com/SuryadevChippada/NODUS/discussions)
for:

- "How do I...?" questions
- General feedback or ideas
- Configuration or usage help
- Anything that isn't a confirmed bug or a concrete, actionable feature
  request

## GitHub Issues — bugs and concrete feature requests

Use [Issues](https://github.com/SuryadevChippada/NODUS/issues) for:

- Reproducible bugs (use the Bug report template)
- Specific, actionable feature requests (use the Feature request
  template)
- Requests to support a specific local runtime or model provider (use
  the Provider request template)

Please search existing issues and discussions before opening a new one.

## Security issues

Do not use Issues or Discussions for security vulnerabilities. See
[SECURITY.md](SECURITY.md).

## Privacy

Never post API keys, access tokens, full prompts containing personal
information, or model files in any support channel.
